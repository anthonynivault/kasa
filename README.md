# Kasa - Plateforme de location immobilière

Projet réalisé dans le cadre de la formation Développeur Web d'OpenClassrooms.

## Description

Kasa est une plateforme de location immobilière permettant aux utilisateurs de consulter des annonces de logements.

L'objectif de ce projet était de développer l'intégralité de l'interface utilisateur avec React en respectant une maquette fournie et en mettant en place une architecture moderne basée sur les composants.

Le projet met l'accent sur la réutilisabilité des composants, la gestion de la navigation et le développement d'une application monopage.

## Compétences développées

* Développement d'une application React
* Création de composants réutilisables
* Gestion du routage avec React Router
* Gestion des erreurs et page 404
* Manipulation des données JSON
* Gestion des props et du rendu dynamique
* Organisation d'un projet React
* Stylisation avec Sass

## Technologies utilisées

* React
* React Router DOM
* Vite
* Sass (SCSS)
* JavaScript (ES6)

## Fonctionnalités

* Affichage dynamique des logements
* Navigation entre les différentes pages
* Page détail pour chaque logement
* Galerie d'images avec navigation
* Système de tags
* Affichage de la note du logement
* Composants Collapse réutilisables
* Gestion des routes inexistantes avec une page 404
* Interface responsive

## Architecture

Le projet est organisé autour de composants React réutilisables :

### Pages

* Accueil
* À propos
* Fiche logement
* Page 404

### Composants

* Header
* Footer
* Banner
* Card
* Collapse
* Slideshow
* Rating
* Tags

## Installation

### 1. Cloner le dépôt

```bash
git clone <url-du-repo>
```

### 2. Installer les dépendances

```bash
npm install
```

### 3. Lancer le serveur de développement

```bash
npm run dev
```

### 4. Accéder à l'application

Ouvrir le navigateur à l'adresse indiquée dans le terminal
